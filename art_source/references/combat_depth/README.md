# Referencias de profundidad en combate

Las tres imágenes `bar_0x_zones.jpg` conservan las indicaciones visuales
entregadas para cada interior:

- rojo: mobiliario de primer plano, situado por encima de personajes y enemigos;
- verde: zona válida para los pies del protagonista;
- lila: zona válida para los pies de los enemigos.

Las guías no se importan ni se exportan con Godot. Las capas transparentes
listas para el juego viven en `assets/backgrounds/combat/`. Las coordenadas de
los pies se definen por interior en `scripts/combat.gd`.
